# 청년문화패스 통합앱 프로토타입

청년국가재정마스터 5기 21팀 · 청년문화예술패스 분석 보고서 후속 프로토타입.
신청, 지역·관심 분야 선택, 맞춤 공연 추천, 잔여 지원금 알림, 예매처 리디렉션, 이벤트·쿠폰, 만족도 조사를 한 앱에서 체험할 수 있습니다.

> 모든 공연·가격·쿠폰은 **예시 데이터**입니다.

## 실행
빌드 과정이 없습니다. `index.html`을 브라우저로 열거나 로컬 서버를 실행하세요.

```bash
python3 -m http.server 8000   # http://localhost:8000
```

## 구조
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 뼈대 |
| `style.css` | 디자인 토큰(라이트/다크), 컴포넌트 스타일 |
| `data.js` | 지역, 분야, 제도 시나리오(2026/2027안), 공연·이벤트·쿠폰 예시 데이터 |
| `app.js` | 상태 관리와 화면 렌더링 (온보딩, 홈, 공연 찾기, 혜택, MY) |

## GitHub Pages 배포
1. 저장소를 만들어 push
2. Settings → Pages → Source를 **GitHub Actions**로 선택
3. `main`에 push하면 `.github/workflows/pages.yml`이 자동 배포

## 실서비스 전환 시 과제
- 예매처(인터파크/YES24) 공연·좌석·잔여석 데이터 연동 가능 여부 확인
- 포인트 잔액 조회 방식 (현재는 앱이 사용 내역을 직접 기록)
- 기한 알림은 데모 고정값(17일) → 발급일/7월 말 회수 규칙으로 계산
- 영화 관람 횟수 제한(수도권 2회/비수도권 5회) 표시
- 상태 저장(현재는 메모리, 새로고침 시 초기화) → localStorage 또는 서버
